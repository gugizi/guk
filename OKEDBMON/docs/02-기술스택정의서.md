# OKEDBMON 기술 스택 정의서

- 제품명: OKEDBMON
- 버전: 1.0.0.0
- 기준일: 2026-11-14

## 1. 개요

브라우저 정적 화면이 수집서버 API를 조회한다. DB 서버의 Python 에이전트는 인스턴스 하나를 수집해 수집서버로 보낸다. 수집서버는 SQLite에 성능, 세션, SQL, 환경 설정을 저장하고 화면을 제공한다.

## 2. 구성 요소

| 구분 | 기술 | 용도 |
|---|---|---|
| UI | HTML5, CSS3, Vanilla JavaScript | `web/index.html`, `web/app.js`, `web/styles.css` |
| 차트 | 인라인 SVG | 추이, 수집단위 막대, SQL 분포 점 |
| 수집서버 | Python 3.10+, FastAPI, Uvicorn | 화면 API와 수집 수신. 포트 8080 |
| 에이전트 | Python, httpx | 인스턴스 하나 수집 후 `POST /api/ingest` |
| Oracle | python-oracledb | `V$SESSION`, `V$SQL`, `V$SYSSTAT` |
| MariaDB | PyMySQL | `performance_schema`를 쓸 수 있으면 사용 |
| PostgreSQL | psycopg 3 | `pg_stat_activity` |
| Tibero | jaydebeapi + JDBC | `TIBERO_JDBC_JAR`. 패키지 목록에는 포함하지 않음 |
| 저장소 | SQLite WAL `data/okedbmon.sqlite` | 성능, 세션, SQL, 설정, 로그인 |
| 검증 | pytest | `OKEDBMON/tests` |
| 문서 | Markdown | `docs/` |

React, Vue, 번들러, ORM은 쓰지 않는다.

## 3. 런타임

| 구분 | 요구 |
|---|---|
| 브라우저 | Chrome, Edge. `fetch`, `localStorage` |
| 수집서버 / 에이전트 PC | Python 3.10 이상. 첫 실행 때 `.venv`를 만든다 |
| OS | Windows, Linux, WSL |
| 포트 | 수집서버 8080. 에이전트는 별도 조회 포트를 열지 않는다 |

## 4. 디렉터리

```
OKEDBMON/
  collector/          수집서버, 스키마, 보관, API
  agent/              인스턴스 하나 수집. Oracle, Tibero, MariaDB, PostgreSQL, simulate
  web/                화면
  config/             default.properties, agent.json
  tests/
  docs/
  run_collector.bat / run_collector.sh
  run_agent.bat / run_agent.sh
  requirements.txt
  CHANGELOG.md
  data/okedbmon.sqlite    실행 후 생성. 저장소에 넣지 않음
```

## 5. 데이터 계층

```
[브라우저]
  localStorage okedbmon_token, okedbmon_alias
  Authorization: Bearer
        |
        v
[수집서버 FastAPI :8080]
  data/okedbmon.sqlite
        ^
        |  POST /api/ingest   X-Agent-Token
[DB 서버 에이전트 1프로세스 = 인스턴스 1개]
  oracledb / pymysql / psycopg / jaydebeapi
  또는 mode=simulate
```

세션, 세션 이력, SQL Text, SQL 통계, 성능, 이벤트는 모두 수집서버 SQLite에 있다.

## 6. 보안 전제

| 항목 | 현재 |
|---|---|
| 로그인 | PBKDF2-HMAC-SHA256. 토큰 12시간. `Authorization: Bearer` |
| 에이전트 | `X-Agent-Token`. 기본값 `okedbmon-agent`. 설정 `agent.token`과 같아야 한다 |
| DB 비밀번호 | `config/agent.json`에만 둔다. 수집서버 화면에는 다시 표시하지 않는다 |
| 초기 비밀번호 | 새 DB에만 `admin` / `okedbmon` 해시를 넣는다 |

## 7. 버전

버전은 주.부.수정.빌드 네 자리(`*.*.*.*`)이다. `collector/version.py`의 `VERSION`과 `config/default.properties`의 `support.ver`가 같다. 화면 표시는 `OKEDBMON V` + 버전이다. 예전 제목 SpaceMon, OKEMON은 기동 시 OKEDBMON으로 바꾼다.
