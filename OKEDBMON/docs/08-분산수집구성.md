# OKEDBMON 분산 수집 구성

- 버전: 1.0.0.0
- 기준일: 2026-11-14

## 1. 저장 책임

```
[DB 서버]
  에이전트 프로세스 1개 = 인스턴스 1개
    ├─ 그 인스턴스만 수집
    ├─ Active Session, Session History, SQL Text, 성능 수치를 구성
    └─ POST /api/ingest
              |
              v
[수집서버 :8080]
  data/okedbmon.sqlite
    ├─ o_performance, event_log
    ├─ active_session, session_history
    ├─ sql_text, sql_stat
    └─ 인스턴스, 로그인, 보관, 환경설정
```

수집서버가 세션과 SQL을 저장한다. 에이전트는 조회용 포트를 열지 않고, 수집 결과를 보내기만 한다. 에이전트가 멈춘 뒤에도 이미 받은 세션과 SQL은 수집서버에서 조회된다. 이후 수집분은 에이전트가 다시 실행될 때부터 쌓인다.

DB 서버가 넷이면 에이전트 프로세스도 넷이다. 한 프로세스가 대상 목록을 순서대로 돌지 않는다.

## 2. 수집서버 설치

1. 수집서버 장비에 소스를 두고 `OKEDBMON`에서 `run_collector`를 실행한다.
2. `config/default.properties`의 `agent.token`을 바꾼다.
3. `collector.host`는 `0.0.0.0`, `collector.port`는 8080이다.
4. 방화벽에서 화면 사용자와 DB 서버 에이전트가 TCP 8080으로 접속할 수 있게 한다.
5. 브라우저에서 `http://<수집서버 IP>:8080/` 으로 로그인한다.

## 3. DB 서버 에이전트 설치

1. 그 DB 서버에 같은 `OKEDBMON` 소스를 둔다.
2. `config/agent.json`의 `target`을 하나 둔다.
3. `collector_url`은 수집서버 주소, `token`은 수집서버 `agent.token`과 같게 한다.
4. `agent_alias`는 수집서버에 등록한 인스턴스 별칭과 같게 한다.
5. `mode`는 실 DB면 `live`, 샘플이면 `simulate`다.
6. `run_agent`를 실행한다.

```json
{
  "collector_url": "http://수집서버:8080",
  "token": "okedbmon-agent",
  "interval_sec": 5,
  "target": {
    "agent_alias": "ORA_PROD",
    "product": "ORACLE",
    "host": "127.0.0.1",
    "port": 1521,
    "database": "ORCL",
    "user": "monitor",
    "password": "",
    "mode": "live"
  }
}
```

DB 비밀번호는 이 파일에만 둔다. 수집 주기는 `target.interval_sec`가 있으면 그 값이고, 없으면 설정의 `interval_sec`다. 최소는 2초다.

## 4. 조회 흐름

- 수집: 에이전트 → 수집서버 `POST /api/ingest` → `okedbmon.sqlite`
- 실시간 Active Session: 브라우저 → 수집서버의 마지막 `active_session`
- 시점별 Active Session: 브라우저 → `GET /api/sessions/series`로 막대, `GET /api/sessions/active?at=`로 그 시각의 행
- Session History, SQL, SQL Trace: 브라우저 → 수집서버의 `session_history`, `sql_text`, `sql_stat`
- 성능 추이, 이벤트, 보관: 브라우저 → 수집서버

SQL Plan, DISPLAY_CURSOR, Session Kill, SMS는 이 버전에 없다.

## 5. 샘플

실 DB 없이 화면을 보려면 수집서버를 실행하고, `mode`가 `simulate`인 에이전트를 하나 실행한다. 성능 테이블이 비어 있으면 수집서버가 등록된 인스턴스의 최근 1시간 샘플을 먼저 넣는다. 여러 인스턴스를 한 프로세스에서 돌리는 실행 파일은 없다. 인스턴스마다 설정 파일을 따로 두고 프로세스를 따로 실행한다.

## 6. 보관

보관 주기 화면에서 종류별 일수를 저장하면 수집서버만 지운다. 에이전트에는 세션 파일과 삭제 주기가 없다. 기본 주기는 60초마다 한 번 검사한다.
