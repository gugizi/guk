# OKEDBMON 코드 컨벤션

- 버전: 1.0.0.0
- 기준일: 2026-11-14

## 1. 언어·파일

| 종류 | 규칙 |
|---|---|
| 수집서버 | `collector/`. Python 3. UTF-8 |
| 에이전트 | `agent/`. 프로세스 하나는 `config/agent.json`의 `target` 하나만 수집 |
| 화면 | `web/app.js`, `web/styles.css`, `web/index.html`. 번들하지 않음 |
| 버전 | 주.부.수정.빌드 네 자리. `collector/version.py`와 `config/default.properties`의 `support.ver` |
| 화면 표시 | `OKEDBMON V` + 버전. `display_name()` |
| 테스트 | `tests/test_monitor.py`. `pytest` |
| 배치 | `*.bat`는 CRLF, `*.sh`는 LF |
| 문서 | `docs/*.md` |

## 2. 이름

- 제품명 OKEDBMON.
- DBMS 순서 Oracle, Tibero, MariaDB, PostgreSQL. 코드 값은 `ORACLE`, `TIBERO`, `MARIADB`, `POSTGRESQL`.
- 저장 파일명은 `data/okedbmon.sqlite`.
- 수집 시각 컬럼은 `agent_collect_tm`.
- 브라우저 키는 `okedbmon_token`, `okedbmon_alias`.
- 에이전트 헤더는 `X-Agent-Token`.

## 3. JavaScript

- 화면 상태는 `state`. 페이지 함수는 `pageX`.
- HTML에 넣는 문자열은 `esc`.
- 숫자 표시는 `num`.
- 자동 갱신 중 이전 요청의 응답은 `stillCurrent`로 버린다.
- 401이면 토큰을 지우고 로그인 화면으로 돌아간다.
- 수집 실패를 샘플 행으로 바꾸지 않는다. 샘플 수치는 `mode: simulate`와 빈 DB의 초기 채우기만 만든다.

## 4. Python

- 타입 힌트를 쓴다.
- SQL 식별자는 코드의 고정 이름만 붙인다. 요청 문자열을 테이블명에 그대로 붙이지 않는다.
- SQLite 연결은 스레드 로컬이다. 로그인 토큰 확인은 잠금 안에서 한다.
- 수집 본문의 세션과 SQL은 `ingest` 한 트랜잭션에서 성능 행과 함께 저장한다.
- 에이전트 설정에 `target`이 둘 이상이면 기동하지 않는다.
- 예외로 수집이 실패하면 그 주기는 오류 상태만 보내고 프로세스는 다음 주기를 계속한다.

## 5. CSS

- 색은 `web/styles.css` 상단 변수. 헤더 `#1b1b1b`, 강조 `#e36b2c`.
- 새 화면은 `.panel`, `.toolbar`, `.table-wrap`을 재사용한다.
- 상세는 `.window-back` 안의 `.window`다.

## 6. 배포 반영

화면 파일을 고치면 브라우저가 옛 파일을 보지 않도록 `web/index.html`의 `?v=`를 올린다. 수집서버 Python을 고친 뒤에는 수집서버 프로세스를 다시 실행한다.

## 7. 금지

- 세 자리(`A.B.C`) 버전
- 한 에이전트 프로세스가 인스턴스 목록을 순서대로 수집하는 것
- DB 비밀번호나 데모 사이트 비밀번호를 소스에 넣는 것
- `data/okedbmon.sqlite`와 `.venv`를 저장소에 넣는 것
- 배치 파일에 한글을 넣는 것
