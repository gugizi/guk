# OKEDBMON 테이블 정의서

- 버전: 1.0.0.0
- 기준일: 2026-11-14
- 시각 형식: `YYYY-MM-DD HH:MM:SS`

## 1. 설정

### 1.1 app_user

| 컬럼 | 타입 | 설명 |
|---|---|---|
| user_id | TEXT | PK |
| password_hash | TEXT | PBKDF2 해시 |
| display_name | TEXT | 화면 표시 이름 |
| role | TEXT | 초기 계정은 admin |

새 데이터베이스의 초기 계정은 `admin`이다.

### 1.2 auth_token

| 컬럼 | 타입 | 설명 |
|---|---|---|
| token | TEXT | PK |
| user_id | TEXT | |
| expires_at | TEXT | 발급 후 12시간 |

토큰은 만료 시각만 검사하고, 로그아웃 때 행을 지우지 않는다.

### 1.3 env_setting

| 컬럼 | 타입 | 설명 |
|---|---|---|
| setting_key | TEXT | PK |
| setting_value | TEXT | |
| description | TEXT | |
| updated_at | TEXT | |

주요 키: `support.title`, `support.ver`, `agent.token`, `collect.interval.sec`, `threshold.cpu`, `threshold.active_sessions`, `threshold.lock_wait`, `threshold.buffer_hit`, `retention.*.days`, `db.repository.path`.

### 1.4 retention_policy

| 컬럼 | 타입 | 설명 |
|---|---|---|
| data_kind | TEXT | PK. performance, active_session, session_history, sql_stat, sql_text, event |
| keep_days | INTEGER | 0이면 현재 시각보다 이전 행 삭제 |
| enabled | INTEGER | 0이면 삭제하지 않음 |
| last_purge_at | TEXT | |
| last_deleted | INTEGER | 마지막 삭제 건수 |

### 1.5 purge_log

`ran_at`, `data_kind`, `keep_days`, `deleted_rows`.

### 1.6 mon_instance

| 컬럼 | 타입 | 설명 |
|---|---|---|
| agent_alias | TEXT | PK. 에이전트 설정의 별칭과 같아야 함 |
| product | TEXT | ORACLE, TIBERO, MARIADB, POSTGRESQL |
| host_nm, port, db_name, username | | 화면 표시용. 접속 비밀번호는 없음 |
| group_nm | TEXT | 좌측 목록 그룹 |
| collect_interval_sec | INTEGER | |
| enabled | INTEGER | |
| description, created_at | | |

처음 생성하는 DB에는 ORA_PROD, TIB_ERP, MARIA_WEB, PG_ANALYTICS가 들어 있다.

## 2. 수집

### 2.1 agent_heartbeat

PK `agent_alias`. `product`, `last_seen`, `status`, `message`, `version`, `agent_url`.

### 2.2 o_performance

수집 1회당 1행. UNIQUE (`agent_alias`, `agent_collect_tm`).

| 컬럼 | 설명 |
|---|---|
| instance_nm | |
| cpu_usage, mem_usage | |
| active_sessions, connected_sessions, lock_wait | |
| buffer_cache_ratio | |
| execute_cnt, user_commits, user_rollbacks | |
| physical_reads, logical_reads | |
| tps, qps, redo_size, parse_hard | |
| wait_user_io, wait_lock, wait_cpu, wait_network | |
| tablespace_used_pct | |
| extra_json | DBMS별 추가 값 |

### 2.3 active_session

그 수집 시각의 세션 1행. 같은 별칭·같은 `agent_collect_tm`은 수신 때 교체한다.

| 컬럼 | 설명 |
|---|---|
| sid, serial_number | |
| status | ACTIVE, INACTIVE 등 |
| db_user, os_user, program, module, machine | |
| sql_id, sql_text | |
| wait_event, wait_class | |
| elapsed_ms, blocking_sid | Lock 대기는 blocking_sid |
| cpu_used, logical_reads, physical_reads, command | |

### 2.4 session_history

`active_session`과 같은 세션 컬럼에 `source`가 있다. 샘플 수집은 `sample`이다.

### 2.5 sql_text

PK (`agent_alias`, `sql_id`). `sql_text`, `command_type`, `db_user`, `first_seen`, `last_seen`. 같은 SQL이 다시 오면 전문과 `last_seen`을 갱신한다.

### 2.6 sql_stat

수집 구간 1행. `agent_alias`, `agent_collect_tm`, `sql_id`, `executions`, `elapsed_ms`, `cpu_ms`, `buffer_gets`, `disk_reads`, `rows_processed`, `db_user`, `program`.

화면의 회당 수행시간은 `elapsed_ms / executions`다.

### 2.7 event_log

`agent_alias`, `occurred_at`, `event_cd`, `event_nm`, `severity`, `message`. CPU, Active Session, Lock, Buffer Hit가 임계치를 넘으면 수집 수신 때 넣는다.

## 3. 연결

SQLite는 WAL이다. 연결은 스레드마다 따로 둔다. 쓰기는 수집서버의 잠금 안에서 한다.
